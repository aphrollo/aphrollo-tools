# File-to-package manifest for the internal/tdd split. Read by tools/tddsplit.
#
# `root` is the unsplit package's directory. [packages] lists every target:
# name, level (a package may import only lower levels; `prep` = created by a
# prep PR, never moved by the generator) and directory (whose base name must
# equal the package name). [files] maps every file of internal/tdd, keyed
# relative to the package directory it lives in; a key ending in `/` maps a
# whole directory (testdata, fuzz corpora). The generator refuses a file with
# no entry. An entry marked `created by P2` names a file the relocations
# below create.
#
# [relocate] lists the symbols the P2 prep PRs move between files of the
# unsplit package so that each file maps to exactly one target: symbol,
# from-file, to-file. A `T.m` row is a method moving with its type; methods
# declared in the from-file beside their type move with it. The rows are the
# fixpoint of the level rule over the reference graph (a symbol used by a
# lower or same-level sibling package moves to the lowest package using it,
# or to the general package one level below when two siblings tie), with the
# destinations the spec names pinned: Runner, Outcome, GateResult, the
# gate-log parse and the small utilities to core; the trunk helpers to gitx;
# the SuiteResult/SuiteRunner/RunSuite group and runCargoLocked to suite.
# A symbol declared in a parenthesized const or var block moves out of that
# block alone, except the GCKind enum, whose iota block moves whole.
#
# Test files map to the lowest package that can compile them: the package
# their production references reach highest, or the root when two packages
# tie at that level. A comment marks each one whose file-name prefix would
# have put it lower.
